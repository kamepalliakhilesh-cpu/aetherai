## ⚡ Windows Laptop Action Execution Engine

* **App Launcher**: Open VS Code, Chrome, Spotify, Terminal, Discord, Calculator, Task Manager, Notepad.
* **Optical Screen Vision**: Capture active display and pass to Gemini Vision for debugging and window analysis.
* **Master Volume & Media Control**: Control Windows volume levels, mute/unmute, and toggle media playback.
* **System Operations**: Instant screen lock (`LockWorkStation`), suspend/sleep, and empty Recycle Bin.
* **Dual Intelligence**: Works completely offline for core system commands, or with Gemini 2.0 Flash / OpenRouter for natural multimodal conversation when your API key is provided.
